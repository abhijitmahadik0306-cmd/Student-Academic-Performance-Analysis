# 📊 Student Academic Performance Analysis

## 📌 Project Overview

Student Academic Performance Analysis is a Python-based data analysis project designed to explore, analyze, and understand students' academic performance using data analytics and interactive visualizations.

The project focuses on identifying patterns and relationships between different factors affecting students' examination scores.

Using Python libraries such as Pandas, Matplotlib, Seaborn, and Plotly, the project performs data cleaning, preprocessing, exploratory data analysis (EDA), and interactive visualization.

The main objective is to transform raw student performance data into meaningful insights that help understand academic outcomes.

## 🎯 Project Objectives

* To analyze student academic performance using Python.
* To clean and preprocess the student dataset.
* To identify missing values and handle data inconsistencies.
* To examine the relationship between attendance and examination scores.
* To analyze student marks distribution.
* To compare academic performance across genders.
* To identify correlations between numerical variables.
* To analyze the ratio of passing and failing students.
* To identify the top 10 performing students.
* To generate meaningful insights through interactive visualizations.

## 📈 Key Visualizations

The project includes the following interactive charts:

1. **Attendance vs Examination Scores:** Examines the relationship between student attendance and marks.

2. **Distribution of Student Marks:** Displays the distribution of examination scores using a histogram.

3. **Gender-wise Performance Analysis:** Compares examination score distributions across genders.

4. **Correlation Heatmap:** Displays correlations between numerical variables.

5. **Pass vs Fail Analysis:** Visualizes the number of students passing and failing based on the defined score threshold.

6. **Top 10 Students:** Identifies students with the highest examination scores.

## 🚀 How to Run the Project

### Step 1: Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/Student-Academic-Performance-Analysis.git
```

### Step 2: Open the Project Folder

```bash
cd Student-Academic-Performance-Analysis
```

### Step 3: Install Required Libraries

```bash
pip install -r requirements.txt
```

### Step 4: Open Jupyter Notebook

```bash
jupyter notebook
```

### Step 5: Run the Notebook

Open `Student_Analysis.ipynb` and execute the cells sequentially.

Make sure the dataset file is available in the project folder.
